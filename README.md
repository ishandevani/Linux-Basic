# Linux Basics: Essential Commands & Hands-On Tasks

# Description
A beginner-friendly Linux practice guide covering essential commands for creating and renaming files/directories, viewing file contents, searching with grep, compressing and extracting files, downloading files with wget, changing permissions with chmod, and working with environment variables using export. The guide includes practical commands and terminal examples to build foundational Linux skills for DevOps and cybersecurity roles.

1. Creating and Renaming Files/Directories
2. Viewing File Contents
3. Searching for Patterns
4. Zipping and Unzipping
5. Downloading Files
6. Changing Permissions
7. Working with Environment Variables
